## 02 — Typography

### Typefaces

**Cabinet Grotesk** — Primary Sans-Serif
- Weights available: Regular (400), Medium (500), Bold (700), Black (900)
- Weights in use: Regular (400), Medium (500), Bold (700), Black (900)
- Used for: wordmark "Linework" (Black), navigation, section headings, service names, buttons

**Satoshi** — Body Sans-Serif
- Weights available: Light (300), Regular (400), Medium (500), Bold (700), Extra Bold (800), Black (900) via variable font
- Weights in use: Light (300), Regular (400), Medium (500), Bold (700)
- Used for: "Land Surveying" descriptor (Light), body copy, captions, contact details

**Bespoke Serif** — Display Serif (Variable, 100–900)
- Weights available: Light (300), Regular (400), Medium (500), Bold (700), Extra Bold (800), Black (900)
- Used for: page titles, display headings, CTA band headlines, editorial subheadings

### Type Scale

| Role | Typeface | Weight | Size |
|------|----------|--------|------|
| Hero / Wordmark | Cabinet Grotesk | Black (900) | clamp(4rem, 10vw, 8.5rem) |
| Wordmark Descriptor | Satoshi | Light (300) | ~58% of wordmark size · no custom tracking or leading |
| Display Heading | Bespoke Serif | 700 | clamp(2.4rem, 5vw, 4rem) |
| Section Heading | Cabinet Grotesk | 700 | clamp(1.8rem, 3vw, 2.6rem) |
| Card Heading | Cabinet Grotesk | 700 | clamp(1.2rem, 2vw, 1.6rem) |
| Body | Satoshi | 400 | 0.95rem / line-height 1.8 |
| Eyebrow / Label | Cabinet Grotesk | 500 | 0.7rem / +0.14em tracking / uppercase |
| Nav Links | Cabinet Grotesk | 500 | 0.8rem / +0.1em tracking / uppercase |

## 03 — Logomark

### Wordmark
- **"Linework"** — Cabinet Grotesk Black (900), no custom tracking or leading
- **"Land Surveying"** — Satoshi Light (300), approximately 58% of wordmark size, left-aligned below
- The descriptor always matches the wordmark color — it is never independently colored

### Color Combinations

| Background | Wordmark | Descriptor |
|------------|----------|------------|
| White (#FFFFFF) | Dark Khaki (#413B25) | Dark Khaki (#413B25) |
| Ivory (#F7F3E3) | Dark Khaki (#413B25) | Dark Khaki (#413B25) |
| Dark (#1A1714) | Ivory (#F7F3E3) | Ivory (#F7F3E3) |
| Any color background | Ivory (#F7F3E3) | Ivory (#F7F3E3) |

### Monocolor Variants (on ivory backgrounds)
The wordmark may appear in a single mid-tone brand color. Descriptor remains dark.

| Wordmark Color | Permitted |
|----------------|-----------|
| Crimson (#D32240) | Yes — mid tone only |
| Navy (#124E78) | Yes — mid tone only |
| Paprika (#EA5C1F) | Yes — mid tone only |
| Palm (#789048) | Yes — mid tone only |
| Dark versions of any color | No |

### Rules
- Never alter the typefaces, weights, or proportions of the wordmark
- Maintain clear space of at least half the wordmark height on all sides
- The descriptor is never colored independently — it always matches the wordmark
- On light backgrounds with a monocolor wordmark: only the wordmark takes the color, descriptor stays dark
- Only mid-tone color versions are permitted on light backgrounds — no dark versions
